## 🌟 จุดเด่นที่ออกแบบมาเพื่อคุณตาคุณยาย (Senior-Friendly UX/UI)

1. **ตัวหนังสือขนาดใหญ่ สบายตา (High Legibility & Contrast)**
   - ใช้ฟอนต์ภาษาไทย **Prompt** และ **Sarabun** ที่อ่านง่าย ชัดเจน ไม่ปวดตา
   - มีปุ่มปรับขนาดตัวหนังสือได้ถึง 3 ระดับ: **ปกติ (18px)** / **ตัวโต (21px)** / **โตพิเศษ (24px)**
   - ตัวเลขยอดเงินเด่นชัด สีตัดกับพื้นหลัง ไม่ต้องเพ่ง

2. **2 ปุ่มยักษ์ กดง่าย ไม่หลงทาง (Foolproof Big Action Buttons)**
   - 🔴 **จดรายจ่าย (เงินออก)**: ปุ่มสีส้มแดงเด่นชัด สำหรับของกิน ของใช้ ค่ายา
   - 🟢 **จดรายรับ (เงินเข้า)**: ปุ่มสีเขียวเด่นชัด สำหรับเบี้ยคนแก่ ลูกหลานให้ เงินค้าขาย

3. **แป้นพิมพ์ตัวเลขขนาดใหญ่ในตัว (Built-in Big Keypad & Quick Chips)**
   - มีแป้นพิมพ์ตัวเลขปุ่มใหญ่ในแอป ไม่ต้องรอคีย์บอร์ดมือถือเด้งขึ้นมาบังจอ
   - มีปุ่มลัดยอดฮิต: `+20`, `+50`, `+100`, `+500`, `+1,000` แตะครั้งเดียวเพิ่มยอดได้ทันที

4. **🎙️ ระบบสั่งด้วยเสียงภาษาไทย (Thai Voice Input)**
   - มีปุ่มไมโครโฟน แตะแล้วพูดได้ทันที เช่น *"ซื้อกับข้าว 80 บาท"* หรือ *"ค่ายา 120 บาท"* ระบบจะเลือกหมวดหมู่และกรอกจำนวนเงินให้อัตโนมัติ

5. **🔊 ระบบเสียงพูดอ่านยอด (Thai Text-to-Speech)**
   - เมื่อบันทึกเสร็จ ระบบจะอ่านออกเสียงภาษาไทย เช่น *"บันทึกรายจ่าย ค่ากับข้าว 80 บาท เรียบร้อยแล้วค่ะ"*
   - มีปุ่ม *"ฟังสรุป"* เพื่อให้คุณตาคุณยายฟังยอดเงินคงเหลือโดยไม่ต้องอ่านเอง (สามารถเปิด-ปิดเสียงได้ตามต้องการ)

6. **🏷️ หมวดหมู่ตรงกับการใช้ชีวิตประจำวันของผู้สูงอายุ**
   - **รายจ่าย**: 🍲 กับข้าว/ของกิน, 🛒 ตลาด/ของใช้, 💊 ค่ายา/หาหมอ, 💡 ค่าน้ำ-ไฟ-โทรศัพท์, 🙏 ทำบุญ/ช่วยงาน, 🎁 ให้ลูกหลาน, 🚗 ค่ารถ/เดินทาง, 🏡 บ้าน/สวน, 👕 เสื้อผ้า
   - **รายรับ**: 👴 เบี้ยผู้สูงอายุ/บำนาญ, 👨‍👩‍👧 ลูกหลานให้เงิน, 💰 ค้าขาย/ค่าจ้าง, 🌾 ผลผลิตเกษตร, 🏦 ดอกเบี้ย, 🧧 ถูกหวย/โชคลาภ

7. **📊 สรุปยอดรายเดือนเข้าใจง่าย (Monthly Summary)**
   - สรุปให้เห็นว่าในแต่ละเดือนมีเงินเข้าเท่าไหร่ เงินออกเท่าไหร่ และมีเงินเหลือเก็บเท่าไหร่
   - แสดงแถบสีเข้าใจง่ายว่าเงินออกไปกับหมวดหมู่ไหนมากที่สุด

8. **💾 บันทึกข้อมูลอัตโนมัติในเครื่อง (Offline & Private)**
   - ไม่ต้องสมัครสมาชิก ไม่ต้องจำรหัสผ่าน ไม่ต้องต่อเน็ตก็เปิดใช้งานได้
   - มีระบบ **"สำรองข้อมูล" (Export)** และ **"กู้คืนข้อมูล" (Import)** เพื่อให้ลูกหลานช่วยเซฟไฟล์เก็บไว้ได้

9. **📞 ปุ่มลัดโทรหาลูกหลาน / คนดูแล (Emergency Contact)**
   - สามารถบันทึกเบอร์โทรของลูกหลานไว้ในแอป และมีปุ่มโทรออกด่วนได้ในคลิกเดียว

## 📱 วิธีเปิดใช้งานบนมือถือเหมือนแอปจริง (Add to Home Screen)

### สำหรับไอโฟน (iPhone / iPad - Safari):
1. เปิดเว็บไซต์ผ่านเบราว์เซอร์ **Safari**
2. แตะปุ่ม **แชร์ (ไอคอนสี่เหลี่ยมที่มีลูกศรชี้ขึ้น 📤)** ที่แถบด้านล่าง
3. เลื่อนลงมาแล้วเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen ➕)**
4. แตะปุ่ม **"เพิ่ม" (Add)** ที่มุมขวาบน
5. ไอคอนแอป **"สมุดเงินทอง"** จะไปอยู่บนหน้าจอหลัก เปิดใช้งานได้ทุกวันแบบเต็มจอ

### สำหรับแอนดรอยด์ (Android - Chrome):
1. เปิดเว็บไซต์ผ่านเบราว์เซอร์ **Google Chrome**
2. แตะปุ่ม **จุดสามจุด (⋮)** ที่มุมขวาบน
3. เลือก **"ติดตั้งแอป" (Install app)** หรือ **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)**
4. แตะ **"ติดตั้ง"** เพื่อยืนยัน

## 💻 วิธีการรันโปรเจกต์ในเครื่อง (Developer Guide)

โปรเจกต์นี้พัฒนาด้วย **React 19 + Vite 8 + Tailwind CSS v4 + Lucide Icons**

```bash
# ติดตั้ง dependencies
npm.cmd install

# รันในโหมดพัฒนา (Development Server)
npm.cmd run dev

# บิลด์สำหรับ Production
npm.cmd run build

# ทดสอบรันไฟล์บิลด์
npm.cmd run preview
```
